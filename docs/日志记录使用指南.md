# 股票分析日志记录使用指南

## 📋 概述

为了更好地了解股票分析过程中的每一个步骤，我们为TradingAgents系统添加了详细的日志记录功能。通过这些日志，您可以：

- 🔍 **跟踪分析流程**：了解每个分析步骤的执行情况
- 📊 **监控数据获取**：查看数据请求和响应的详细信息
- 🤖 **追踪LLM调用**：记录AI模型的输入输出和性能
- ⚡ **性能分析**：统计各环节的耗时和成本
- 🐛 **错误调试**：快速定位和解决问题

## 🚀 快速开始

### 1. 基础使用

```python
from tradingagents.utils.logger import StockAnalysisLogger

# 创建日志记录器
logger = StockAnalysisLogger(
    log_file="my_analysis.log",  # 可选：日志文件路径
    enable_console=True          # 是否在控制台显示
)

# 开始股票分析并记录日志
stock_code = "000001.SZ"
trade_date = "2024-01-15"

logger.log_analysis_start(stock_code, trade_date)
# ... 执行分析 ...
logger.log_analysis_complete(stock_code, True, 8.5)
```

## 🛠️ 配置选项

### 日志级别配置

```python
import logging

# 详细调试日志
logger = StockAnalysisLogger(log_level=logging.DEBUG)

# 仅重要信息
logger = StockAnalysisLogger(log_level=logging.INFO)

# 仅错误信息  
logger = StockAnalysisLogger(log_level=logging.ERROR)
```

### 日志输出配置

```python
# 仅输出到文件
logger = StockAnalysisLogger(
    log_file="analysis.log",
    enable_console=False
)

# 同时输出到文件和控制台
logger = StockAnalysisLogger(
    log_file="analysis.log", 
    enable_console=True
)

# 仅输出到控制台
logger = StockAnalysisLogger(enable_console=True)
```

    logger = StockAnalysisLogger(log_file=f"analysis_{stock_code}.log")
    
    try:

        raise
