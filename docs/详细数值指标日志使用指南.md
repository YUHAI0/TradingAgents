# 详细数值指标日志使用指南

## 概述

本指南介绍如何使用TradingAgents系统的增强日志功能，该功能可以记录股票分析过程中的所有具体数值指标，帮助您更好地监控和调试分析流程。

## 主要功能特性

### 1. 详细数值记录
- **价格指标**: 开盘价、收盘价、最高价、最低价、涨跌幅等，精确到小数点后4位
- **技术指标**: RSI、MACD、KDJ、布林带等，格式化显示
- **成交数据**: 成交量使用千分位分隔符，成交额显示完整数值
- **移动平均线**: MA5、MA10、MA20等各周期均线数值

### 2. 财务指标记录
- **盈利能力**: 营业收入、净利润（单位：万元），ROE、ROA等比率
- **财务健康**: 资产负债率、流动比率、资本充足率等
- **银行特色**: 不良贷款率、拨备覆盖率等银行业专用指标

### 3. 市场情绪分析
- **情绪评分**: 各数据源的情绪评分（x.x/10格式）
- **新闻统计**: 新闻数量、正负面占比等详细统计
- **热度指数**: 市场关注度量化指标

### 4. 投资建议详情
- **目标价位**: 保守、中性、乐观目标价及止损位
- **风险评估**: 技术、基本面、市场等各维度风险评分
- **操作建议**: 具体的仓位、建仓、止盈止损策略

## 数值格式化规则

### 价格类数据
- **股价**: 保留2位小数 (12.85)
- **涨跌幅**: 保留2位小数 + % (2.80%)
- **成交量**: 千分位分隔符 (45,892,000)

### 技术指标
- **RSI**: 保留4位小数 (65.2300)
- **MACD**: 保留4位小数 (0.1500)
- **比率类**: 保留2位小数 + % (2.34%)

### 财务数据
- **金额**: 转换为万元 + 千分位分隔符
- **比率**: 保留2位小数 + %
- **倍数**: 保留4位小数

### 评分类数据
- **情绪评分**: x.x/10 格式 (7.2/10)
- **风险评分**: 保留2位小数 (3.20)

## 性能优化建议

### 1. 日志级别控制
```python
# 生产环境使用INFO级别
logger = StockAnalysisLogger(log_level=logging.INFO)

# 调试时使用DEBUG级别
logger = StockAnalysisLogger(log_level=logging.DEBUG)
```

### 2. 文件输出优化
```python
# 按日期分割日志文件
from datetime import datetime
log_file = f"analysis_{datetime.now().strftime('%Y%m%d')}.txt"
logger = StockAnalysisLogger(log_file=log_file)
```

### 3. 内存使用控制
```python
# 对于大量数据，限制记录的数据量
if len(data) > 1000:

else:
    logger.log_debug("完整数据", data)
```

## 故障排除

### 常见问题

1. **数值显示不正确**
   - 检查数据类型是否为数值型
   - 确认数据格式是否符合预期

2. **日志文件过大**
   - 使用日志轮转功能
   - 调整日志级别
   - 定期清理旧日志

3. **性能影响**
   - 在生产环境关闭DEBUG级别
   - 避免记录过大的数据对象
   - 使用异步日志记录

### 调试技巧

```python
# 临时启用详细日志
logger.log_debug("调试信息", {"variable": value})

# 记录异常详情
try:
```
